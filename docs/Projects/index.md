# 实验项目

## 贯穿项目：多模态文档检索与分析 Agent

目标是把推理服务、多模态数据处理和 Agent 执行连成一个可测量的系统。下列内容为计划与验收项，完成后应补充代码链接、环境记录和实测结果。

```mermaid
flowchart LR
    A[图片与文档] --> B[解析与预处理]
    B --> C[Embedding / 视觉语言模型]
    C --> D[索引与结构化结果]
    D --> E[检索与分析工具]
    E --> F[Agent 工作流]
    F --> G[质量与性能评测]
```

## 里程碑与验收

- [ ] **M1：单机基线**——固定输入和环境，保存模型调用、预处理和写回的原始耗时。
- [ ] **M2：推理服务**——固定工作负载，记录延迟分位数、吞吐、显存和失败率，并完成一次受控对比。
- [ ] **M3：多模态链路**——为样本记录 ID、版本和失败原因，支持按失败样本重跑。
- [ ] **M4：Agent 闭环**——调用检索和分析工具，验证状态恢复、超时与重复执行处理。
- [ ] **M5：评测与复盘**——在固定任务集上报告质量、性能和资源消耗，解释改进的适用范围。

## 每份实验记录应包含

| 部分 | 建议内容 |
| --- | --- |
| 环境 | 代码提交、依赖版本、设备与驱动、运行参数 |
| 数据 | 样本来源、处理版本、输入尺寸/长度与任务分布 |
| 基线 | 原始配置、测量方法、预热与重复次数 |
| 改动 | 单次改动、预期作用与瓶颈证据 |
| 结果 | 原始数据、质量、延迟、吞吐、显存/内存和失败率 |
| 结论 | 适用条件、未验证部分与下一步实验 |
